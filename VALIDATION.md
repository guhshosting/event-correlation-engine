## Checks completed

- `scripts/build.ps1`: CMake NMake Release, `/W4 /WX /analyze /permissive- /utf-8`. Passed. Includes engine, CLI, fixture tests and live-test helper. `/analyze` is part of compilation, not an unrun optional target. C6553 is suppressed only for the Windows SDK XmlLite declaration with invalid integer/pointer SAL annotation.
- `ctest --test-dir build-native --output-on-failure`: **5/5 passed**, total 0.61 seconds: engine fixtures, help, version, CLI/JSON contract, restricted-live. Run outside the filesystem/process sandbox because its token restrictions prevented creating the test's further restricted token. The standalone restricted-token test also passed outside that sandbox. This approval applies to the developer test, not runtime elevation.
- `scripts/static-analysis.ps1`: clang-tidy analyzer/bugprone checks and Cppcheck warning/performance/portability checks. Passed with zero project findings. clang-tidy reports 1,098 suppressed non-project SDK/STL diagnostics; none is a project-code waiver. The unsafe-to-allow-exceptions opinion check is excluded because MSVC map move construction allocates and can throw, so the correct explicit potentially throwing move declarations otherwise receive contradictory diagnostics. No unsafe move is forced noexcept.
- Fixture tests: UTC/fractional timestamps, leap day, numeric record-ID tie sorting, grouping, inclusive clustering and one-tick boundary, recurring group sets, shared/missing/zero/related activities, computer scope, selected-event matches and preceding/following indices, unavailable messages, empty JSON/results, malformed XML and prohibited DTD, bounded/truncated report, denied/partial status, JSON escaping and no-causality wording. CMake parses fixture JSON and checks null fields and values; CLI contract tests reject invalid numeric bounds, remote/path syntax, duplicate channels, missing anchors and multiple modes.
- `scripts/live-validation.ps1`: local System/Application lookback 60 minutes, maximum 25 events/channel, plus bounded groups, limits of one event/channel, missing channel (exit 3), partial acquisition (exit 0), nonexistent anchor (exit 3), exact level filter, and real System anchor with inclusive +/-60-second window. Ordinary System query succeeded; Security returned access denied; combined query returned useful explicit partial results with at most one event. Production code never performs token operations.
- `scripts/safety-audit.ps1`: passed production source allowlist and direct PE import audit. Event Log calls are EvtQuery, EvtNext, EvtRender, EvtClose, EvtOpenPublisherMetadata, EvtFormatMessage, EvtOpenChannelConfig and EvtGetChannelConfigProperty. The latter two only read enabled state. Imported DLLs: wevtapi.dll, XmlLite.dll, SHLWAPI.dll, KERNEL32.dll. No direct network, shell/process-launch or event-log mutation imports were found. This does not purport to audit Windows DLL internals or constitute a network packet capture.

Local developer evidence is retained in `artifacts/`: build-release.txt, clang-tidy.txt, cppcheck.txt, imports.txt, safety-audit.txt and live-validation.txt.
